I am a **Cloud & DevOps Engineer** with 2+ years of production experience designing, migrating, and optimizing workloads across **Microsoft Azure and AWS**.

I operate with one core principle:

> **If it can be automated — automate it.  
> If it can fail — design for it.  
> If it’s slow — optimize it.**

### 🔥 What I Actually Do

- Migrate on-prem workloads to cloud with near-zero downtime  
- Build Infrastructure as Code using Terraform  
- Design CI/CD pipelines that reduce release friction  
- Containerize services using Docker & deploy to Kubernetes (EKS + local clusters)  
- Implement monitoring stacks for proactive alerting  
- Troubleshoot production incidents under SLA pressure
